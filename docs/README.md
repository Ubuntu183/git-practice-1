\# Документация проекта git-practice-1



Проект содержит программу приветствия на Python 3.

Внешние библиотеки не требуются.



\## Запуск в Windows



Из корня проекта: `py -3 script1.py`.

Результат: `HELLO, FROM PERSON3!`.



\## Тестирование



Из корня проекта: `py -3 -m unittest discover -v`.



\## Документация к коду



Описание модуля и функции находится в docstring в script1.py.

Локальная генерация HTML: `py -3 -m pydoc -w script1`.

Откройте созданный script1.html в браузере.



GitHub Actions автоматически запускает тесты и генерирует HTML

после push и при открытии или обновлении Pull Request.

Результат доступен в Actions → запуск CI → Artifacts → documentation.

HTML создаётся заново для каждого запуска; исходники хранятся в Git.
